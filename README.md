# Rodzinne losowanie prezentów 🎄

Strona bez serwera i bez logowania. Cała aplikacja to jeden plik: `index.html`.

- Organizator wpisuje uczestników i pary, które nie losują siebie nawzajem.
- Strona tworzy osobny link dla każdego uczestnika. Wynik jest zapisany w samym linku.
- Uczestnik widzi, kogo wylosował, informacje o wydarzeniu i może dodać przypomnienie do kalendarza.
- Organizator ma ukryty podgląd wyników oraz link, który pozwala do niego wrócić.
